basededatos: contiene las credenciales a la base de datos SQL 
controlador: lógica de negocio y revisión de JSON
rutas: redirige las solicitudes hacia controladores según tipo de petición http (GET, POST, etc.) 
modelos: toma los datos del controlador y los traduce a SQL

server.js: toma la conexion de la base de datos y configura el servidor express
